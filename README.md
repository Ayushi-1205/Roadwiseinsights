# RoadWise Insights

I want to redesign the frontend of an existing project called Smart Road Safety Intelligence Platform.

The project is a road accident analytics and safety intelligence platform.

For now, I only want to create the frontend UI/UX. Do not create the backend or database yet.

The frontend should look like a premium professional SaaS analytics platform, similar in quality to modern enterprise data visualization products.

The application should have:

 Modern professional dashboard

 Sidebar navigation

 Top navigation/header

 KPI cards

 Interactive charts

 Accident analytics

 Accident hotspot map

 Accident cause analysis

 Vehicle-wise analysis

 Weather and road-condition analysis

 Reports section

 Responsive design

 Clean typography

 Professional icons

 Subtle animations and micro-interactions

 Excellent spacing and visual hierarchy

Use a sophisticated road-safety/analytics visual style. Avoid making it look like a generic admin dashboard or a basic student project.

Important: First create only the frontend structure and visual design. Do not worry about connecting APIs or databases yet.
